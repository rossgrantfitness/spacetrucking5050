# Reference images (mood board)

Pictures the developer collected to show the look we're going for. They're
**for inspiration only**: they are other people's artwork, so they never go
into the game itself. (A hidden `.gdignore` file tells Godot to skip this
folder, so these images aren't imported or exported with the game.)

| File | What we take from it |
|---|---|
| `ship_bb42_cargo_aircraft.webp` | The player's rig: gunmetal fuselage, amber cockpit glass, silver engine pods with yellow trim, swept wings, room for a crew of 4-5. |
| `ship_capsule_hauler_sketch.png` | The "capsule hauler" traffic ship: a long rounded tank body with boxy engine pods. |
| `ship_capital_with_escorts.png` | Big ships passing with little ones around them (for the big-ship flyby in M5). |
| `ship_big_freighter_over_planet.webp` | Huge, detailed freighters and an oversized planet below: scale and mood. |
| `hud_wipeout3_race.webp`, `hud_wipeout3_special_edition.webp` | The HUD: slanted segmented bars, yellow outlines, big chunky slanted digits. Also the chunky late-PS1 texture look and blue engine flares. |
| `hud_scifi_elements_cyan.webp` | Cyan sci-fi HUD shapes (brackets, rings, segmented bars) for markers and menus. |
| `look_colony_wars_space.png` | The space look we're aiming for: late PS1 (1999-2000), black space with soft nebula bands, a rainbow arc gauge. |
| `look_dino_crisis_interior.png` | Late-PS1 interiors for the hub (M3): clean, detailed textures and fixed camera angles. |
| `hub_neon_food_stand.webp` | The hub (M3): a cozy PS1 food stand with paper lanterns and a neon sign in alien script. |

Add more any time; mention them in chat so Claude looks at them.
