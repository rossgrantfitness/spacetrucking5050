# Decisions

One line per decision: what, and why. Newest at the bottom. Anything here can
be revisited; just say so.

## 2026-10-03 (M0: Setup)

- **Engine: Godot 4.7.2 stable, GDScript only.** It was the latest stable 4.x release when the project was created.
- **Renderer: Compatibility (OpenGL 3.3).** It runs on the widest range of computers (older laptops, integrated graphics, Steam Deck), and the PSX look needs none of Forward+'s fancy features. Custom shaders, depth fog and low-res viewports all work here.
- **Window: 1280×720 base size, "canvas_items" stretch, "expand" aspect.** Text and UI stay crisp and readable at any window size. The chunky low-res 3D will come from a separate low-res viewport in M4.
- **File names: PascalCase for scripts and scenes, snake_case for data files.** This matches the names in CLAUDE.md (`GameState.gd`, `ShipVisual.tscn`, `tuning.tres`).
- **Added a `Settings` autoload (not in the original list)** for player comfort options, saved to `user://settings.json`. Options belong to the player, not to one save slot.
- **Autoload order: Events, SaveSystem, Settings, GameState, Economy, TimeOfDay, Radio, Dialogue.** Each one can safely use the ones before it while the game starts up.
- **Scripts reach tuning through `GameState.tuning`.** There's one shared copy of `res://data/tuning.tres`. The values written in `Tuning.gd` are starting values; anything changed in the Inspector is saved in `tuning.tres` and wins.
- **Tuning only holds values something actually uses.** Each milestone adds its own group, so there are no dead knobs in the Inspector.
- **Default keyboard controls:** W/S throttle, A/D or ←/→ steer, ↑/↓ nose up/down, Space boost, C camera, E interact, Esc pause, plus the mouse steering in flight. This keeps the left hand on WASD and leaves the mouse free to steer.
- **Default gamepad controls:** left stick steers, RT/LT throttle, A boost (and interact on foot), Y camera, Start pause, right stick looks around. This is racing-game muscle memory, with the big friendly A button for the fun thing.
- **Invert Y is off by default (stick up = nose up).** That matches "the ship goes where it points". Pilot style is one switch away, and we ask about it in the M0 playtest.
- **Keys are bound by physical position, and on-screen hints show the player's real key labels.** WASD then works on French/German keyboards too.
- **Gamepad bindings listen to any controller (device -1).** Otherwise only the first controller plugged in would work.
- **The input map is generated by `tools/setup_input_map.gd`.** Godot writes it in its own exact format. Editing it in *Project Settings → Input Map* is fine too.
- **Mouse steering is a "virtual stick".** Moving the mouse pushes a stick that drifts back to center (tunable). We can revisit this in M1 once you can feel it.
- **Analog steering uses `Input.get_vector` with Tuning's `stick_deadzone`.** That gives a round deadzone and a smooth ramp. The Input Map deadzones only decide when an action counts as "pressed".
- **Frame-rate-independent smoothing everywhere (`1 - exp(-speed * delta)`).** Easing then feels the same at 30 or 240 FPS.
- **The boot screen is the main scene for now.** In M0 it's the setup check; later it can become a dev launcher and then the main menu.
- **`CLAUDE.md` is committed to the repo.** The design brief travels with the project and loads automatically in every session.
- **Empty planned folders stay in git via hidden `.gitkeep` files.** Godot hides dot-files, so the editor stays clean.
- **Validation runs through `tools/validate.sh`.** It imports the project, loads every file with GDScript warnings treated as errors, runs the self-tests in `tools/tests/` (a tiny homemade runner, no plugins), then runs the main scene and fails on any error or warning.
- **`tools/capture.sh` takes visual checks.** It renders frames with Godot's Movie Maker mode on a virtual screen, so Claude can look at the game without a monitor.
- **Cloud sessions auto-install Godot** via a Claude Code SessionStart hook (`.claude/`). It only runs in Claude's cloud sessions and does nothing on your computer.
- **Placeholder project icon:** a sleepy bunny chewing a wheat stalk (`icon.svg`). Swap it any time.
